# Помощник по контракту

Рабочая папка для ведения государственного контракта в Claude Code: следит за сроками,
строит план отправки документов и готовит официальные письма по шаблонам.

Подробная инструкция для человека — **[НАЧАТЬ_ОТСЮДА.md](НАЧАТЬ_ОТСЮДА.md)**.
Правила, по которым работает ИИ, — [CLAUDE.md](CLAUDE.md).

## Что внутри

| Папка | Содержимое |
|---|---|
| `1_Документы_контракта/` | Контракт, ТЗ, приложения |
| `2_Шаблоны_писем/` | Шаблоны официальных писем с полями `{{...}}` и заготовки |
| `3_Правила_и_регламенты/` | Регламенты, правила оформления, накопленные правки по письмам |
| `4_План_и_журнал/` | Паспорт контракта, журнал событий, план в четырёх форматах, реестр писем |
| `5_Готовые_письма/` | Подготовленные письма с версиями |
| `scripts/` | Шесть скриптов на стандартном Python — ничего устанавливать не нужно |

## Скрипты

| Скрипт | Назначение |
|---|---|
| `read_doc.py` | Читает .docx / .odt / .txt |
| `workdays.py` | Считает рабочие дни по производственному календарю |
| `update_calendar.py` | Обновляет календарь из открытых данных (xmlcalendar) |
| `make_plan.py` | Строит план: Excel, Word, Confluence, календарь .ics |
| `make_letter.py` | Готовит письмо по шаблону, ведёт версии |
| `start_pack.py` | Готовит сразу пачку писем — старт контракта или начало этапа |
| `registry.py` | Реестр исходящих писем и их статусы |
| `check.py` | Проверяет готовность: данные, шаблоны, календарь, журнал |

## Как это работает

Сроки в техническом задании двух видов: жёсткие даты этапов и сроки, привязанные к событиям
(«в течение 5 рабочих дней с даты заключения контракта»). Поэтому план собирается из двух
источников: обязательства, выписанные из контракта и ТЗ с указанием пунктов-оснований, и журнал
событий, куда человек отмечает факты. После каждой отметки план пересчитывается.

Письма собираются из шаблонов организации: подставляются реквизиты, номера и даты, ведутся
версии под несколько кругов вычитки. Накопленные правки хранятся в
`3_Правила_и_регламенты/ПРАВКИ_И_ЗАМЕЧАНИЯ.md` и применяются во всех последующих письмах.

Помощник не отправляет письма, не подписывает документы и не работает в ЕИС — это делает человек.
